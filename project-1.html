Student Event Booking App

A responsive web application that lets students browse and book society events.

Type
Year 1 group coursework
My role
Front-end developer
Duration
8 weeks
Technologies
HTML, CSS, JavaScript, Firebase

This is a holding page. Screenshots, a link to the code repository and a live demo will be added here.

Overview

Student societies advertised events across several social media channels, which made it hard for students to find out what was on. Our team built a single, mobile-friendly site listing all upcoming events with the option to reserve a place.

What I did

  • Built the responsive event listing layout using CSS Grid.
  • Created the booking form with client-side validation and accessible error messages.
  • Added category filters so students could narrow down events.
  • Managed our shared GitHub repository and reviewed pull requests.

What I learned

This project taught me how to divide work across a team using GitHub issues and branches, and showed me how much difference early accessibility decisions make to the final product.
