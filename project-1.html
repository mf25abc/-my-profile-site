QuizMaster Quiz Web App

A quiz website with user accounts, multiple quiz categories, scoring, a leaderboard and an admin panel, built with Python and Flask.

Type
University group coursework
My role
Back-end developer (core logic)
Technologies
Python, Flask, Flask-Login, SQLAlchemy, SQLite, Jinja2, HTML, CSS, JavaScript

This is a holding page. Screenshots of the app and a link to the code repository will be added here.

Overview

QuizMaster lets users create an account, pick a quiz category (Science, History, Technology or Geography), answer multiple-choice questions with a progress bar, and get their score with feedback. Scores are saved so users can see their recent results and compare themselves with others on a leaderboard. An admin panel lets an administrator add and delete categories and questions without touching the code.

What I did

My main work in the team was the back-end core logic:

  • Handled the routes (URLs) in Flask for registration, login, quizzes, results, the leaderboard and the admin panel.
  • Wrote the quiz logic that checks each submitted answer and calculates the score.
  • Managed users, including secure login with hashed passwords and admin-only access.
  • Connected the app to the SQLite database, with tables for users, categories, questions and scores.

What I learned

This project showed me how data flows through a web application: the user opens the site, the front end sends a request to Flask, and Flask processes it, talks to the database and returns a page. Working in a team also taught me how to split a project into front-end and back-end responsibilities and agree on how the parts connect.
