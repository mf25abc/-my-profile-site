Library Database System

A relational database and Python command-line interface for managing book loans in a small library.

Type
Year 1 individual coursework
My role
Sole developer
Duration
6 weeks
Technologies
Python, SQL, SQLite

This is a holding page. An entity relationship diagram, sample queries and a link to the code repository will be added here.

Overview

The brief was to replace a spreadsheet-based loan record with a proper database. I designed a normalised schema covering members, books, copies and loans, then wrote a Python program to carry out everyday tasks.

What I did

  • Designed the schema to third normal form and drew the ER diagram.
  • Wrote SQL queries for issuing, returning and reporting overdue loans.
  • Built a menu-driven Python interface with input validation.
  • Wrote unit tests for the main database functions.

What I learned

I learned how good data modelling prevents problems later on, and how parameterised queries protect against SQL injection.
