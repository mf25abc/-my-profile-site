Technical interests

The areas of computing I am most interested in and want to develop further on placement.

Front-end web development

I am interested in how the interfaces people use every day are designed and built. I enjoy the mix of logic and visual design that front-end work involves, from structuring semantic HTML to writing maintainable CSS layouts and adding behaviour with JavaScript. I am particularly keen to learn how professional teams use component-based frameworks and design systems to keep large interfaces consistent.

Through coursework and personal projects I have come to appreciate that good front-end work is about performance and reliability as much as appearance. I would like a placement where I can work on a real product and see how front-end decisions affect the people who use it.

Web accessibility

Accessibility means making sure websites work for everyone, including people who use screen readers, keyboards or magnification. I became interested in it after learning that many common sites fail basic WCAG checks, which shuts out a large number of users. I now try to build accessibility in from the start, using semantic markup, sufficient colour contrast and clear focus states.

I want to deepen my understanding of the Web Content Accessibility Guidelines and of testing with assistive technologies, so that I can help teams build products that are inclusive by default rather than fixed afterwards.

Cloud computing and deployment

I am interested in how modern applications are hosted, scaled and delivered. Using services such as GitHub Pages has shown me how quickly code can move from a repository to a live site, and I am curious about the wider tooling behind this, including continuous integration, containers and managed cloud platforms.

On placement I would like to understand how teams automate testing and deployment so that changes reach users safely and frequently.
