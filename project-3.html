Accessibility Audit of a Charity Website

A review of a public charity website against WCAG 2.2 level AA, with a prioritised list of recommendations.

Type
Personal project
My role
Auditor and report author
Duration
3 weeks
Tools
WAVE, keyboard testing, WCAG 2.2

This is a holding page. The full audit report will be added here.

Overview

Many charities rely on their websites for donations and support services, so barriers can stop people getting help. I chose a public charity website and reviewed its main user journeys against WCAG 2.2 level AA.

What I did

  • Ran automated checks on key pages and recorded the results.
  • Tested every journey using only a keyboard.
  • Checked colour contrast, headings, link text and form labels.
  • Wrote a report ranking issues by impact, with suggested fixes.

What I learned

Automated tools find only part of the picture; manual checks such as keyboard testing revealed issues that no tool reported.
